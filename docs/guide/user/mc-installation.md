# Installing Neoforge, Minecraft and Foundry Engine

To Install Minecraft, get either the official Minecraft Launcher, or
what I recommend, [Prism Launcher](https://prismlauncher.org/).
Both of these launchers will allow you to install the version of Minecraft you want to use with Foundry Engine.

Next, you will need to install Neoforge. You can do this by following the instructions on
the [Neoforge website](https://neoforged.net//).

Finally, you will need to install the Foundry Engine mod.
You can do this via [Modrinth](https://modrinth.com/discover/mods), or by downloading the mod from inside your Launcher,
if you are using Prism Launcher.
