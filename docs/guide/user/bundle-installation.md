# Installation

If you want to just Install a bundle created with Foundry Engine, you can do so by following these steps:

1. Download the Bundle you want to install. This should be a folder!
2. Move the Bundle Folder to the `bundles` directory located in `.minecraft/FondryEngine/bundles.`
3. Restart Minecraft if it is currently running, and the Bundle should now be loaded and ready to use!

If you encounter any issues with the Bundle not loading, make sure to check your logs.
