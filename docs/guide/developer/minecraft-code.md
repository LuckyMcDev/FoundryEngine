# Minecraft Source Code

This wiki points to minecraft source code via [McSrc.dev](https://mcsrc.dev/1/26.1/)
This is a website which shows you the minecraft source code. I would generally look at this website if you have any
questions about Minecraft, as its quite helpful.

There is also the option to look at the javadoc created by LadyLexxieBlack.
You can find it here: https://lexxie.dev/neoforge/26.1/
It is harder to read, but shows the methods exposed by
Minecraft, Blaze3D and NeoForge, which can be more helpful than the source code in some cases.
