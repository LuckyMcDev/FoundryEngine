# Sounds and particles

This page points to the supported sound workflow and records the current particle boundary.

## Register a sound

Register a sound from a common entrypoint with `SoundBuilder`, place the sound file under `assets/<bundleId>/sounds/`, and add any subtitle translation to the bundle's language JSON. Follow the complete [Add a sound](../guides/registration/add-sound) example.

The sound builder creates a sound event and generated sound definition. Sound files and generated definitions are client assets; the event registration is compatibility-mode checked.

## Particles

Client bundle entrypoints load during client setup, after registry registration has finished. Bundle scripts therefore cannot register particle types through `BundleEvents.registry`; Java extensions that register content before registry events can use the [ParticleBuilder reference](../guides/builders/ParticleBuilder).
