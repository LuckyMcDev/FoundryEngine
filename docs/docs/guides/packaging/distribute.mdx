# Distribute a bundle

A bundle is the folder with your scripts, assets, and data, plus a `.bundles.toml` metadata file. The engine can load a bundle from a directory or a `.zip` archive.

## Share the files

Send the bundle directory or zip it. Place a directory in the bundle directory, or place a `.zip` file directly there. The recipient can restart the game or run `/engine reload` after copying it.

## What the recipient needs

- A compatible Minecraft version and NeoForge build. The current 26.1 target uses Minecraft 26.1.2 and NeoForge 26.1.2.x.
- FoundryEngine installed.
- For singleplayer: just the bundle.
- For a server: the bundle on the server, and the client bundle on every player who needs the content (see [dedicated server](dedicated-server)).

## Version matters

Bundles are tied to the Minecraft version they were built against. A bundle built for one MC version may not load on another. Match the engine version between everyone in a multiplayer game.
