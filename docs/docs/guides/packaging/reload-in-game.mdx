# Reload in game

`/engine reload` re-discovers bundles and reloads their common and server scripts. It requires operator permissions.

```text
/engine reload
```

## What reload does

- Clears engine event callback lists.
- Stops active game sessions.
- Calls `onUnload()` on loaded common and server entrypoints.
- Re-scans bundles, runs common entrypoints, and reloads server entrypoints.
- Re-registers commands and reports script failures.

The command does not rebuild Minecraft registries. Restart after changing items, blocks, recipes, sounds, particles, or other registry content. The engine warns that command and registry state can remain inconsistent during a live reload.

The reload path re-discovers bundles and reloads common and server entrypoints. In an integrated world, a reload-completed callback schedules client entrypoints to reload on the client thread. A dedicated server cannot reload scripts in connected client processes; restart clients after changing their `scripts/client` files.

## In the editor

Save script changes to disk, then run `/engine reload` from the game. Check the console and Problems panel for compilation or entrypoint errors.
