# LevelEvents

**Applies to:** common/server scripts.

`LevelEvents` wraps level load, unload, save, post-tick, and explosion events. Callbacks receive the underlying NeoForge event.

## Events

| Method | When |
| --- | --- |
| `load { event -> ... }` | A level loads. |
| `unload { event -> ... }` | A level unloads. |
| `save { event -> ... }` | A level saves. |
| `tick { event -> ... }` | `LevelTickEvent.Post`, after a level tick. |
| `beforeExplosion { event -> ... }` | `ExplosionEvent.Start`, before an explosion. This event is cancellable. |
| `afterExplosion { event -> ... }` | `ExplosionEvent.Detonate`, during detonation processing. |

## Example

```groovy
LevelEvents.load { event ->
    println "Level loaded: ${event.level.dimension()}"
}
```

Callbacks are cleared on bundle reload. Cancellation and mutation follow each underlying event's NeoForge contract.
