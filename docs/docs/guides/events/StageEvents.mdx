# StageEvents

**Applies to:** server-side bundle scripts. Each callback receives a `GameStageEvent` with the player and stage identifier.

| Registration | Timing | Cancellation |
| --- | --- | --- |
| `adding { event -> ... }` | Before the stage is added. | Cancellable; cancel to prevent the addition. |
| `added { event -> ... }` | After the stage was added. | Not cancellable. |
| `removing { event -> ... }` | Before the stage is removed. | Cancellable; cancel to prevent removal. |
| `removed { event -> ... }` | After the stage was removed. | Not cancellable. |

```groovy
StageEvents.added { event ->
    println "${event.entity.name} received stage ${event.stage}"
}
```

Listeners clear when bundles reload. The before events implement NeoForge's cancellable event contract; the after events are notifications.
