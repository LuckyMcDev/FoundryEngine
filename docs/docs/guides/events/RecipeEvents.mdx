# RecipeEvents

**Applies to:** common bundle scripts.

These callbacks receive NeoForge events. FoundryEngine clears their listeners when bundles reload. They are registered on the mod event bus, so callbacks run at the corresponding event even when the originating bundle did not just reload.

| Method | Event | Timing and scope |
| --- | --- | --- |
| `recipesReceived` | `RecipesReceivedEvent` | Client-side recipe synchronization after the server sends recipes. |
| `modifyRecipes` | `ModifyRecipeJsonsEvent` | Data/resource loading hook for modifying recipe JSON before recipes are built. |

```groovy
RecipeEvents.recipesReceived { event ->
    println "Recipes synchronized"
}
```

Use the event's own API to inspect or modify recipe data. This example only observes synchronization; recipe edits belong in the pre-build modification event, not in `recipesReceived`.
