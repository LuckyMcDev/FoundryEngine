# Events

Events are the hook points your bundle can react to. Each event type is a global bus that fires at a specific moment; you subscribe with a closure and read or change the data in the event object.

- [BundleEvents](BundleEvents): registration-time events and bundle lifecycle.
- [PlayerEvents](PlayerEvents): player actions such as joining, ticking, and breaking blocks.
- [BlockEvents](BlockEvents): block-level events.
- [EntityEvents](EntityEvents): entity lifecycle and combat events.
- [GameEvents](GameEvents): game session lifecycle events.
- [ServerEvents](ServerEvents): server startup, shutdown, ticks, and tag updates.
- [ClientEvents](ClientEvents): client lifecycle, input, chat, and rendering hooks.
- [ItemEvents](ItemEvents): item interaction events.
- [LevelEvents](LevelEvents): level lifecycle and world events.
- [StageEvents](StageEvents): stage adding and removing.
- [DialogueEvents](DialogueEvents): dialogue start, progress, option, and end events.
- [CommandEvents](CommandEvents): register commands.
- [SlotEvents](SlotEvents): container slot events.
- [NetworkEvents](NetworkEvents): custom network data events.
- [RecipeEvents](RecipeEvents): recipe sync and modification events.
- [Data generation](DataEvents): bundle data-generation hooks.
