# EntityEvents

**Applies to:** common bundle scripts. `hurt` reports post-damage values; it cannot cancel damage.

The callbacks receive NeoForge event objects. FoundryEngine clears these listeners when bundles reload.

| Method | Event | Behavior |
| --- | --- | --- |
| `joinLevel` | `EntityJoinLevelEvent` | An entity joins a level. |
| `death` | `LivingDeathEvent` | A living entity is about to die; the underlying event is cancellable. |
| `drops` | `LivingDropsEvent` | Living entity drops are available for modification. |
| `hurt` | `LivingDamageEvent.Post` | Damage has been applied; observation only. |

```groovy
EntityEvents.death { event ->
    def entity = event.entity
    def killer = event.getSource().getEntity()
    println "${entity.name} died${killer != null ? ' to ' + killer.name : ''}"
}
```

The death callback can cancel the underlying event with `event.setCanceled(true)` where the event permits cancellation. The example only observes it.
