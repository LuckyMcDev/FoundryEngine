# EntityEvents

`EntityEvents` posts callbacks around entity actions. Each callback receives an event object with fields like `event.entity`.

## Events

| Method | When |
| --- | --- |
| `joinLevel { event -> ... }` | An entity joins a level. |
| `death { event -> ... }` | An entity dies. Event exposes `entity` and `source` (the damage source). |
| `drops { event -> ... }` | An entity's drops are calculated. Event exposes the drop list. |
| `hurt { event -> ... }` | An entity is damaged (after damage is applied). |

## Example

```groovy
EntityEvents.death { event ->
    def entity = event.entity
    def killer = event.source.getEntity()
    println "${entity.name} died${killer != null ? ' to ' + killer.name : ''}"
}
```
