# NetworkEvents

**Applies to:** common bundle scripts. Registering custom packet types is Java extensions only.

## Event

| Registration | Timing and payload |
| --- | --- |
| `onCustomDataReceived { event -> ... }` | Engine custom data is received. The event exposes `player`, `id`, and `data` (`CompoundTag`). |

## Example

```groovy
NetworkEvents.onCustomDataReceived { event ->
    println "Received ${event.id} from ${event.player.name}: ${event.data}"
}
```

The event is observational; it has no cancellation or mutation methods. Its callback list clears when bundles reload. For Java packet registration, see the [networking guide](../networking) and [NetworkManager Javadoc](pathname:///javadoc/de/luckymcdev/foundryengine/network/common/NetworkManager.html).
