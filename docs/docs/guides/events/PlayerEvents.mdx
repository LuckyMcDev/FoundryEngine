# PlayerEvents

**Applies to:** common/server bundle scripts. Callbacks receive NeoForge server event objects.

## Events

| Registration | Payload and timing |
| --- | --- |
| `loggedIn` / `loggedOut` | `PlayerLoggedInEvent` and `PlayerLoggedOutEvent`. |
| `respawned` | `PlayerRespawnEvent`. |
| `tick` | `PlayerTickEvent.Post`, once per player after that player's tick. |
| `chat` | `ServerChatEvent` when a server player sends chat. |
| `advancement` | `AdvancementEarnEvent`. |
| `chestOpened` / `chestClosed` | `PlayerContainerEvent.Open` and `.Close`. |

## Example

```groovy
PlayerEvents.loggedIn { event ->
    println "Player joined: ${event.entity.name}"
}
```

The callback receives the original event, including its native cancellation behavior where supported. The facade does not add `postLoggedIn`, `postLoggedOut`, or `postTick` callbacks. Listener callbacks are cleared during bundle reload.
