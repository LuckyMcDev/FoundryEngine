# GameEvents

**Applies to:** server-side bundle scripts.

`GameEvents` posts callbacks around game session state changes. Each callback receives an event with `event.sessionId` (the `Identifier` of the session).

## Events

| Method | When |
| --- | --- |
| `onStarting { event -> ... }` | Before a game session starts. Cancellable. |
| `onStarted { event -> ... }` | After a game session starts. |
| `onStopping { event -> ... }` | Before a game session stops. Cancellable. |
| `onStopped { event -> ... }` | After a game session stops. |

## Example

```groovy
GameEvents.onStarted { event ->
    println "Session ${event.sessionId} started!"
}
```

Each callback receives `GameSessionEvent` and its `sessionId`. Listener callbacks clear during bundle reload.
