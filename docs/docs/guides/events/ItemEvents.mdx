# ItemEvents

**Applies to:** common/server scripts; empty-click events are client-side.

`ItemEvents` posts callbacks around item interactions. Each callback receives the relevant NeoForge event object.

## Events

| Method | When |
| --- | --- |
| `pickedUp { event -> ... }` | An item entity is picked up by a player. |
| `destroyed { event -> ... }` | A player's item is destroyed, for example when it breaks. |
| `rightClicked { event -> ... }` | A player right-clicks while holding an item. |
| `crafted { event -> ... }` | A player crafts an item. |
| `dropped { event -> ... }` | A player drops an item. |
| `foodEaten { event -> ... }` | A player finishes eating food. |
| `smelted { event -> ... }` | An item is smelted for a player. |
| `dynamicTooltips { event -> ... }` | Item tooltips are being built. Modify the tooltip list here. |
| `entityInteracted { event -> ... }` | A player interacts with an entity while holding an item. |
| `firstLeftClicked { event -> ... }` | Client `LeftClickEmpty` event. |
| `firstRightClicked { event -> ... }` | Client `RightClickEmpty` event. |
| `modification { event -> ... }` | An item is being modified (default components). |

## Example

```groovy
ItemEvents.crafted { event ->
    println "Player crafted: ${event.crafting}"
}
```

The callback argument is the corresponding NeoForge event, except `modification`, which receives FoundryEngine's `ItemModificationEvent`. Event mutation and cancellation follow the payload type. Listener callbacks clear during bundle reload; client-entrypoint listeners are not restored by `/engine reload` until the client restarts.
