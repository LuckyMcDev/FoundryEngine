# BlockEvents

**Applies to:** common/server bundle scripts. Callbacks receive the corresponding NeoForge event object.

## Events

| Registration | Payload and timing |
| --- | --- |
| `broken { event -> ... }` | `BreakBlockEvent` when a block is broken. |
| `placed { event -> ... }` | `BlockEvent.EntityPlaceEvent` when an entity places a block. |
| `neighborNotify { event -> ... }` | `BlockEvent.NeighborNotifyEvent`. |
| `leftClicked { event -> ... }` | `PlayerInteractEvent.LeftClickBlock`. |
| `rightClicked { event -> ... }` | `PlayerInteractEvent.RightClickBlock`. |
| `farmlandTrampled { event -> ... }` | `BlockEvent.FarmlandTrampleEvent`. |
| `modification { event -> ... }` | Engine `BlockModificationEvent`, posted for engine blocks so their supported properties can be changed. |

## Example

```groovy
BlockEvents.broken { event ->
    println "Block broken at ${event.pos}"
}
```

The payload is the underlying event, so available properties and cancellation behavior depend on that event class. `BlockModificationEvent` provides mutation methods such as `hasCollision(boolean)`, `soundType(SoundType)`, and `lightEmission(int)`. Listener callbacks are cleared on bundle reload. The facade has no separate `postBroken` or `postPlaced` methods.
