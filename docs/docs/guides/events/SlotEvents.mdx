# SlotEvents

**Applies to:** common/server bundle scripts. The callback receives an `AbstractContainerMenu` directly.

## Event

| Registration | Timing and payload |
| --- | --- |
| `modification { menu -> ... }` | Runs when a player opens a container. The argument is `event.getContainer()` from `PlayerContainerEvent.Open`, not an event wrapper. |

```groovy
SlotEvents.modification { menu ->
    println "Opened container ${menu}"
}
```

The menu is the live container, so changes to its slots affect that menu instance. Listener callbacks clear on bundle reload. The facade does not provide a separate close callback.
