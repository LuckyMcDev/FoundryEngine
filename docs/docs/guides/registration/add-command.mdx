# Add a command

**Applies to:** server bundle scripts for server commands; client bundle scripts for client commands. Client entrypoints load during client setup. Integrated-world bundle reloads reload client entrypoints; dedicated servers cannot reload remote clients.

This entrypoint registers `/hello` on the server command dispatcher:

```groovy title="scripts/server/mybundle/CommandEntrypoint.groovy"
package server.mybundle

import com.mojang.brigadier.Command
import de.luckymcdev.foundryengine.event.common.CommandEvents
import de.luckymcdev.foundryengine.script.common.BundleEntrypoint
import net.minecraft.commands.Commands
import net.minecraft.network.chat.Component

class CommandEntrypoint implements BundleEntrypoint {
    @Override
    void onLoad() {
        CommandEvents.register { event ->
            event.dispatcher.register(
                Commands.literal("hello").executes { context ->
                    context.source.sendSuccess(Component.literal("Hello from mybundle!"), false)
                    Command.SINGLE_SUCCESS
                }
            )
        }
    }

    @Override
    void onUnload() {}
}
```

Use Brigadier argument types to add arguments. This example uses a string argument and the imports used by the showcase bundle:

```groovy
import com.mojang.brigadier.arguments.StringArgumentType

Commands.literal("greet")
    .then(Commands.argument("name", StringArgumentType.word())
        .executes { context ->
            def name = StringArgumentType.getString(context, "name")
            context.source.sendSuccess(Component.literal("Hello, ${name}!"), false)
            Command.SINGLE_SUCCESS
        })
```

`CommandEvents.register` receives the server `RegisterCommandsEvent`; `registerClient` receives `RegisterClientCommandsEvent` and is client-only. These callbacks are cleared and re-registered on bundle reload.
