# Add a particle

**Applies to:** Java extensions that register content before registry events. Although `scripts/client` entrypoints now load during client setup, that is after registry registration; a client bundle script cannot register a `ParticleBuilder` through `BundleEvents.registry` at that point.

The Java API creates a `ParticleBuilder`, configures particle data, and passes it to the engine's registry integration before registry events. Use [ParticleBuilder Javadoc](pathname:///javadoc/de/luckymcdev/foundryengine/builder/common/particle/ParticleBuilder.html) for its Java signatures. Bundle scripts load too late to register particle types.

## What each call does

| Call | Effect |
| --- | --- |
| `.lifetime(n)` | Particle lives for `n` ticks. |
| `.layer(ParticleLayer.TRANSLUCENT)` | Render layer; `OPAQUE` for solid particles. |
| `.color(start, end, easing)` | Color fades from start to end. |
| `.scaleData(...)` | Size over time, driven by keyframes. |
| `.velocity(Vector3d)` | Sets the particle's initial speed vector. |
| `.alwaysShow()` | Visible regardless of the player's particle settings. |
