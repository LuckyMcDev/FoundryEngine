# Add a recipe

**Applies to:** common bundle scripts. Recipes are data generated for the server.

This complete entrypoint registers three recipes. Each recipe needs an unlock criterion to appear in the recipe book.

```groovy title="scripts/common/mybundle/RecipeEntrypoint.groovy"
package common.mybundle

import de.luckymcdev.foundryengine.builder.common.recipe.RecipeBuilder
import de.luckymcdev.foundryengine.event.common.BundleEvents
import de.luckymcdev.foundryengine.script.common.BundleEntrypoint
import net.minecraft.advancements.criterion.InventoryChangeTrigger
import net.minecraft.resources.Identifier
import net.minecraft.world.item.Items

class RecipeEntrypoint implements BundleEntrypoint {
    private static Identifier id(String path) {
        Identifier.fromNamespaceAndPath("mybundle", path)
    }

    @Override
    void onLoad() {
        def shaped = RecipeBuilder.shaped(id("wand_from_diamond"), Items.DIAMOND_HORSE_ARMOR)
            .pattern(" D ", " S ", " S ")
            .define('D' as char, Items.DIAMOND)
            .define('S' as char, Items.STICK)
            .unlockedBy("has_diamond", InventoryChangeTrigger.TriggerInstance.hasItems(Items.DIAMOND))

        def shapeless = RecipeBuilder.shapeless(id("gems_from_diamond"), Items.DIAMOND)
            .requires(Items.DIAMOND)
            .requires(Items.EMERALD)
            .count(3)
            .unlockedBy("has_diamond", InventoryChangeTrigger.TriggerInstance.hasItems(Items.DIAMOND))

        def smelting = RecipeBuilder.smelting(id("smelt_smooth"), Items.SMOOTH_STONE)
            .ingredient(Items.STONE)
            .experience(0.5f)
            .cookingTime(200)
            .unlockedBy("has_stone", InventoryChangeTrigger.TriggerInstance.hasItems(Items.STONE))

        BundleEvents.registry { event ->
            event.recipes(shaped, shapeless, smelting)
        }
    }

    @Override
    void onUnload() {}
}
```

The shaped recipe maps characters to ingredients. Shapeless recipes use `.requires`; cooking recipes use `.ingredient`, `.experience`, and `.cookingTime`. `RecipeBuilder` also supports blasting, smoking, campfire cooking, stonecutting, and smithing recipes.
