# Add a sound

A sound event is registered from a **common** entrypoint. The sound file and generated sound definition are client assets.

## Use the SoundBuilder

```groovy title="scripts/common/mybundle/SoundEntrypoint.groovy"
package common.mybundle

import de.luckymcdev.foundryengine.builder.common.sound.SoundBuilder
import de.luckymcdev.foundryengine.event.common.BundleEvents
import de.luckymcdev.foundryengine.script.common.BundleEntrypoint
import net.minecraft.resources.Identifier

class SoundEntrypoint implements BundleEntrypoint {
    private static Identifier id(String path) {
        Identifier.fromNamespaceAndPath("mybundle", path)
    }

    @Override
    void onLoad() {
        def chime = SoundBuilder.create(id("magic_chime"))
            .subtitle("subtitles.mybundle.magic_chime")
            .addSound(id("magic_chime"))
            .range(16.0f)

        BundleEvents.registry { event ->
            event.sounds(chime)
        }
    }

    @Override
    void onUnload() {}
}
```

`SoundBuilder.create()` defines the sound event. `.addSound()` points at the sound file. `.subtitle()` takes a localization key, not the displayed text.

## Add the audio file

Place the audio at `assets/mybundle/sounds/magic_chime.ogg`. The path after `assets/mybundle/sounds/` has to match the path you pass to `.addSound()`. `addSound(id)` uses defaults; the overload accepts volume, pitch, weight, streaming, attenuation distance, and preload settings. Add the subtitle translation in `assets/mybundle/lang/en_us.json`:

```json
{
  "subtitles.mybundle.magic_chime": "Magic chime"
}
```

The sound event can be played through Minecraft's sound APIs. `.range()` selects a fixed audible range; omit it to use the variable-range event.
