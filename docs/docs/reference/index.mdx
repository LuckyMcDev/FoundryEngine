# Reference

Reference pages describe the supported engine surface by subsystem. Use the guides for a working task, then use these pages to find the related types and constraints.

## Bundle authoring

- [Content and registration](content-and-registration): the content types exposed by the registry and builder APIs.
- [Events](../guides/events/): event groups, timing, and event payloads.
- [Bundle metadata](../guides/bundle-metadata): `*.bundles.toml` fields and dependencies.
- [Entrypoint lifecycle](../guides/entrypoint-lifecycle): script environments and load order.

## Runtime services

- [Saved data](../guides/saved-data): section scopes, persistence, and synchronization.
- [Networking](../guides/networking): packet bounds and delivery helpers.
- [Runtime worlds](../guides/world/runtime-worlds): runtime level configuration and lifecycle.
- [Managers](../guides/managers): shared engine services.

## Generated API

The [Javadoc](pathname:///javadoc/) contains signatures for the Java API. The Docusaurus pages explain the supported use cases and link the relevant types without duplicating every method signature.
