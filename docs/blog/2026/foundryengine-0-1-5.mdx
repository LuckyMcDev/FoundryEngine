FoundryEngine 0.1.6 is out!
The First Ever Public Release

**Foundry Engine** is a NeoForge mod for Minecraft 26.1 that turns the game into a game engine.
You write content in Groovy as a Bundle: a self-contained folder of scripts, textures, and data.
Since Scripts are written in Groovy, they are hot reloadable (except for registry changes (Yet!)).

Make items, blocks, recipes, sounds, and particles.
Build areas, waypoints, branching dialogue, game stages, cutscenes, and custom dimensions.
Add post-processing effects and a full in-game editor. Iterate live, then share your bundle as a folder.

**Downloads:** [CurseForge](https://www.curseforge.com/minecraft/mc-mods/foundry-engine) · [Modrinth](https://modrinth.com/project/foundryengine) · [GitHub](https://github.com/LuckyMcDev/FoundryEngine) · [Bundle template](https://github.com/LuckyMcDev/ExampleBundle)
