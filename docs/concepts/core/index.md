# Core concepts overview

FoundryEngine's core concepts form the foundation for building Minecraft content without writing Java. Each concept is documented in detail on its own page.

| Concept                            | Description                                                                          |
|------------------------------------|--------------------------------------------------------------------------------------|
| [Bundles](bundles)                 | The fundamental packaging unit (scripts, assets, data, and blueprints in one folder) |
| [Scripts and Entrypoints](scripts) | Groovy scripting engine with entrypoint and helper scripts                           |
| [Builders](builders)               | Fluent API for creating items, blocks, recipes, sounds, and particles                |
| [Registries](registries)           | How custom content is registered with the game                                       |
| [Events](events)                   | Over 80 events across 16 categories                                                  |
| [Sides](sides)                     | Client/server separation and what goes where                                         |
| [Dependencies](dependencies)       | Bundle and mod dependency syntax                                                     |
| [Bundle Config](config)            | Per-bundle TOML configuration with typed values                                      |

Start with [Bundles](bundles) to understand the packaging model. Then explore the rest based on what you need to build.
