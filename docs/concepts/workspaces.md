# Concepts: Development Environments

A Development Environment is in the Foundry Engine context,
Either the folder inside the `.minecraft/FoundryEngine/bundles/bundleName` in this case called
bundleName, Or when using the TemplateBundle, the `src/main/groovy` & `src/main/resources` folders.

If I referer to "scripts directory", that can mean either one.
Same with Resource- and Data-Pack.
